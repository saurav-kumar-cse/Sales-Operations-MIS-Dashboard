# Sales & Operations MIS Report (Excel)

**Role targeted:** MIS Executive  
**Tools:** Excel (SUMIFS, COUNTIFS, AVERAGEIFS, RANK, IFERROR, TEXT, conditional formatting, charts)

## What it is
An automated MIS workbook that turns 600 order records (Apr 2025 - Mar 2026) into management-ready reports: KPI dashboard, region, product, monthly trend and sales-rep scorecard. Data is simulated for portfolio use.

## Sheets
| Sheet | Purpose |
|---|---|
| Dashboard | 6 KPIs + 4 charts |
| About | Project notes and refresh steps |
| Data | Raw order data (filters, frozen header, calculated Net Sales, Cost, Profit, Month) |
| Region Summary | Orders, sales, profit, margin, delivery days, return/cancel % |
| Product Summary | Units, sales, profit, margin, sales share |
| Monthly Trend | Monthly sales, profit, MoM growth |
| Rep Scorecard | Target vs achievement, rank, rating (editable target in yellow cell) |

## Resume bullets
- Built an automated Sales & Operations MIS in Excel from 600+ order records, with a KPI dashboard covering sales, profit, margin, delivery time and return rate.
- Designed 2,500+ live formulas (SUMIFS, COUNTIFS, RANK, IFERROR) so reports refresh automatically when new data is pasted in.
- Created a sales-rep scorecard with target-vs-achievement tracking and conditional formatting to flag under-performers.

## Interview talking points
- Why only "Delivered" orders count toward sales and profit.
- How to refresh: paste new rows into Data, formulas copy down, extend ranges.
- Insights to state: Laptops drive ~45% of sales; Accessories and Headphones have the highest margins; West region has the lowest return/cancel rate.
